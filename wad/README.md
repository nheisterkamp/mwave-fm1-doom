# Game data

Put a Doom IWAD here; `tools/build.py` packs from `wad/doom1.wad` unless told otherwise (`--iwad`).

- **doom1.wad**, the shareware Doom v1.9 (4 196 020 bytes, SHA-1 `5b2e249b9c5133ec987b3ea77596381dc0d6bc1d`):
  the one this port is made for. id Software allows it to be shared unmodified; it is not in this repository.
- Freedoom's maps are much bigger: its E1M1 alone packs to 1.3 MB, twice the room on an FM-1.

A firmware package built from an IWAD carries part of that IWAD's data: share the source, not your builds.
